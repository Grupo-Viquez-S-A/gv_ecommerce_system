Regla para considerar una venta como pagada al 100%:
Usar esta lógica:

1. Obtener órdenes desde production_orders.
2. Obtener su cotización relacionada desde quotations.
3. Obtener los pagos relacionados desde payments.
4. Calcular:
   amountPaid = suma de payments.amount donde payments.is_active = true
   totalSale = quotations.total
   balance = production_orders.balance

5. Mostrar la venta solamente si cumple una de estas condiciones seguras:
   - amountPaid >= totalSale
   O
   - production_orders.payment_status === "pagado" y production_orders.balance <= 0

6. No mostrar la venta si:
   - production_orders.payment_status es "pendiente"
   - production_orders.payment_status es "parcial"
   - production_orders.payment_status es "vencido"
   - production_orders.payment_status es "cancelado"
   - production_orders.balance > 0
   - amountPaid < quotations.total

Importante:
Si existe una inconsistencia, por ejemplo payment_status = "pagado" pero balance > 0 y amountPaid < total, NO mostrarla. Es mejor no mostrar una venta dudosa antes que mostrar una venta no pagada.
